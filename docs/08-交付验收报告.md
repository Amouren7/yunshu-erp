## 5. 已知限制（交接说明）

### 5.1 生产模块交接的 3 条（业务影响需知悉）

1. **完工单位成本为估算值**：完工入库单位成本 = 已领材料成本 × **1.18** ÷ 未完工数量（1.18 为人工与制造费用估算系数）；未领料直接报完工时按物料标准成本估算。适用于演示，不作为正式成本核算依据。
2. **BOM 权限走 `basedata.*`**：BOM 维护页面（`/production/boms`）的增删改使用 `basedata.create/edit/delete` 权限，而非 `production.*`；若角色只有生产权限，需要额外授予基础资料权限才能维护 BOM。
3. **报表驾驶舱部分数据依赖 `dashboard.view`**：经营驾驶舱的销售/采购/毛利趋势、品类占比、客户排行来自 `/api/dashboard/*`；只有 `reports.view` 的账号这些图表可能为空。建议报表角色同时授予 `dashboard.view`。

### 5.2 其他已知限制

| 限制 | 说明 |
|---|---|
| 数据范围口径 | `data_scope`（全部/本部门/本人）**已对单据生效**（列表过滤 + 详情/编辑/审核越权 403）；仪表盘、报表中心、主数据列表仍为全局口径 |
| 负库存策略 | 系统参数「允许负库存」默认开启；关闭后出库/发货/领料会校验可用库存并拒绝（已实现） |
| 凭证更正 | 手工凭证保存即过账、不可修改；暂无"红冲"按钮，需做反向分录 |
| 多币种 | 单据可填币种/汇率，但未做本位币折算与汇兑损益 |
| 单价取价规则 | 取物料参考价，未实现客户协议价/价格表优先级 |
| `/api/health` | 已设为公开健康检查（2026-10-23 修复），可直接用于监控探活 |
| 单元测试 | `npm test` 执行的是 e2e（67 断言）+ 探针（16 断言），`server/tests/` 尚未建立 |
| 并发 | 单进程同步 SQLite，适合演示/小团队；高并发需反代限流或拆分 |

## 6. 质量加固记录

### 6.1 业务边界与权限（2026-10-23 16:00–17:00）

交付后使用边界探针脚本 `scripts/probe.mjs`（隔离库 + 独立端口）对权限、数量、金额、日期、库存等边界做了一轮攻击性测试，**发现并修复 8 个真实缺陷**，修复后探针 16/16 通过：

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | 同一销售订单可被两张发货单重复发货（超发） | 审核时重新校验源单行剩余数量，超出即拒绝（`SOURCE_QTY_EXCEEDED`） |
| 2 | 收款/付款金额可超过发票未结余额，导致发票余额被截断、与资金/总账不一致 | 核销前校验发票剩余余额，超出即拒绝（`INVOICE_OVER_ALLOCATED`） |
| 3 | 系统参数「不允许负库存」不生效，出库仍可为负 | `stockOut` 读取参数并校验可用库存，不足即拒绝 |
| 4 | 仅 `basedata.view` 权限即可读取销售单据列表 | 单据列表/详情按所属模块校验（`sales.view` 等），修复跨模块越权 |
| 5 | 角色 `data_scope=本人/本部门` 未生效，销售专员可见全部单据 | 单据列表按范围过滤；详情/编辑/删除/审核越权返回 403 |
| 6 | 折扣率 200%、税率 9999% 可提交，产生负数金额/异常税额 | 折扣率、税率限定 0~100%，单价/数量不得为负 |
| 7 | 非法日期（如 `2026-13-45`）可入库 | 日期格式与真实性校验（含时区安全） |
| 8 | `/api/health` 未公开，监控探活 401 | 设为公开健康检查接口 |

**修复后回归**：`npm run e2e` 67/67、`node scripts/probe.mjs` 16/16、`node scripts/audit.mjs` 73/73 页面正常、`node scripts/ui-flow.mjs` 16/16；主要改动文件 `server/lib/{posting,docService,stock}.mjs`、`server/api/documents.mjs`、`server/auth.mjs`、`server/seed.mjs`（角色数据范围与制单人归属对齐）。

| 9 | 客户类型/等级/区域、供应商分类/评级、员工类型/状态等 7 个筛选下拉选项空白 | `DataTable` 统一归一化选项（字符串/数字自动转 `{label,value}`，对象数组兼容），修复后 7/7 下拉均有正确选项，选择「重点客户」结果由 30 条筛为 4 条 |
